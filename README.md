# MindTrack 🧠🌿

**Minimalistische Reflexions-App**
*Zen-Look. Privacy First. Intelligente Sortierung.*

## 🎯 Vision
Eine App, die Gedanken automatisch sortiert in:
1.  **Kurzer Impuls** (Neu, einmalig)
2.  **Wiederholter Gedanke** (Gedankenkarussell, bekanntes Thema)

## 🛠 Tech Stack
- **Framework:** React Native (Expo) -> iOS & Android
- **Datenbank:** SQLite (Lokal auf dem Gerät)
- **Logik:** Fuzzy Search / Simple NLP (z.B. `fuse.js`)
- **Design:** Minimalistisch, Salbeigrün/Soft-Blau

## 📂 Struktur
- `/app` - Screens & Navigation
- `/database` - SQLite Setup
- `/utils` - NLP & Vergleichslogik
